# reps-site

Marketing, support and legal pages for the Reps iOS app, served by GitHub Pages at
https://jakeintech.github.io/reps-site/.

Source of truth for `index.html`, `privacy-policy.html`, `support.html`,
`data-deletion.html`, `style.css` and `assets/` is `site/` in Jakeintech/Reps
(copy changes from there). `terms-of-service.html` and `health-disclaimer.html`
live only here for now.

The app links to these exact paths (`Shared/Services/LegalURLs.swift` in the app
repo), so don't rename files.
